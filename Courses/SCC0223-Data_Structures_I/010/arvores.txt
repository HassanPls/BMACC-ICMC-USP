1. CONCEITO E DEFINIÇÃO DE ÁRVORE ENRAIZADA
-------------------------------------------------------------------------------
- Definição: Estrutura de dados NÃO-LINEAR que organiza os elementos com base 
  em um relacionamento HIERÁRQUICO (ao contrário de listas, filas e pilhas, que 
  mantêm uma relação sequencial/linear).
- Definição Recursiva: Uma árvore enraizada T é um conjunto finito de nós 
  (ou vértices) tal que:
  * T = vazio (árvore vazia), OU
  * T = {r} U {T1} U {T2} U ... U {Tn}, onde `r` é um nó especial chamado RAIZ 
    e os demais nós são divididos em n >= 1 conjuntos disjuntos não vazios 
    (T1, T2, ..., Tn), chamados SUBÁRVORES de `r` (cada um também é uma árvore).
- Vantagens e Aplicações:
  * Representa naturalmente hierarquias (árvores genealógicas, sumários de 
    livros, sistemas de arquivos/diretórios, organogramas institucionais).
  * Consulta Seletiva: Permite navegar diretamente para uma ramificação 
    específica sem precisar percorrer toda a estrutura de dados.

2. FORMAS DE REPRESENTAÇÃO DE ÁRVORES
-------------------------------------------------------------------------------
- Grafos (Mais utilizada): Nós representados por círculos/caixas conectados 
  por arestas direcionadas de cima (raiz) para baixo (folhas).
- Conjuntos Aninhados (Diagramas): Círculos/regiões englobando suas subárvores.
- Indentação: Listagem textual hierárquica utilizando recuos (como índices 
  de livros ou exploradores de pastas).
- Representação Aninhada (Sequência de Chaves):
  * Utiliza pares balanceados de `{` e `}` onde o rótulo do nó aparece logo 
    após a abertura `{` correspondente.
  * Exemplo: `T = {D, {E, {F}}, {G, {H, {I}}, {J, {K}, {L}}, {M}}}`

3. TERMINOLOGIA E MÉTRICAS FUNDAMENTAIS
-------------------------------------------------------------------------------
- Relações Genealógicas:
  * Pai e Filho: A raiz `r` é pai das raízes de suas subárvores imediatas; 
    estas são chamadas de filhas de `r`.
  * Irmãos: Nós que possuem o mesmo nó pai.
  * Ancestral e Descendente: `r_i` é ancestral de `r_j` se existe um caminho 
    não-nulo descendo de `r_i` até `r_j` (`r_j` é descendente de `r_i`).
- Grau:
  * Grau de um Nó: Número de subárvores (filhos) ligadas a esse nó.
  * Nó Folha (ou Terminal): Nó com grau igual a 0 (não possui filhos).
  * Nó Interno: Nó que possui pelo menos um filho (grau > 0).
  * Grau da Árvore: O maior grau encontrado entre todos os nós da árvore.
- Distâncias, Altura e Profundidade:
  * Caminho: Sequência de nós `P = {r1, r2, ..., rk}` onde `ri` é pai de `ri+1`.
  * Comprimento do Caminho: Número de arestas no caminho, igual a `k - 1`.
  * Altura de um Nó: Comprimento do caminho mais longo desse nó até uma folha.
    - Nós folhas sempre têm Altura = 0.
    - Altura da Árvore: É igual à altura do nó RAIZ.
  * Profundidade de um Nó: Comprimento do caminho único da RAIZ até esse nó.
    - A raiz sempre tem Profundidade = 0.
  * Nível: Conjunto de todos os nós que possuem a mesma profundidade (raiz 
    está no Nível 0).

4. ÁRVORES N-ÁRIAS
-------------------------------------------------------------------------------
- Definição: Árvore enraizada na qual cada nó pode ter no máximo N subárvores 
  (filhos) ordenadas (i-ésimo filho de v, para 1 <= i <= N).
- Caso Especial Importante (N = 2): Árvores Binárias, onde cada nó possui no 
  máximo 2 filhos (subárvore esquerda e subárvore direita), formando a base 
  para Árvores Binárias de Busca (ABB), AVL e Heaps.
